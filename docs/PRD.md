# 온라인 경쟁 레이싱 게임 — Product Requirements Document (PRD) v1.2

- 문서 상태: Pre-Production
- 장르: 온라인 경쟁 레이싱 + 차량 제작/세팅
- 핵심 경쟁 방식: 상시 ELO 기반 개인전
- 게임 구조: 매칭 → 트랙 공개 → 차량 준비 → 퀄리파잉 → 그랑프리 → ELO
- 플레이 방식: 온라인 개인전
- 핵심 방향: 카트라이더의 접근성 + F1의 레이스 구조/전략 + 차량 제작/세팅 시스템

---

## 1. 게임 한 줄 정의

매칭이 잡힌 순간 공개되는 트랙에 맞춰 자신의 레이싱 머신을 즉석에서 준비하고, 퀄리파잉과 그랑프리를 거쳐 실력에 따라 ELO를 올리는 온라인 경쟁 레이싱 게임.

## 2. 핵심 게임 정체성

플레이어는 단순히 자동차를 운전하지 않는다. 차량 제작 + 차량 세팅 + 트랙 분석 + 퀄리파잉 + 레이스 전략 + 실제 운전을 모두 수행한다.

핵심 재미: **"이번 트랙에서 어떤 차를 준비하고 어떻게 달릴 것인가?"**

## 3. 전체 게임 루프

```
게임 접속 → 경쟁전 선택 → 매칭 시작 → 매칭 완료 → 트랙 공개 → 준비 시간
→ 부품 교체 / 차량 세팅 / 스킨 변경 → 준비 완료 → 퀄리파잉 → 출발 그리드 결정
→ 그랑프리 → 최종 순위 → ELO 계산 → 결과 → 다음 매칭
```

## 4. 경쟁전

경쟁전은 상시 운영된다. 8주 단위의 경쟁 시즌으로 ELO를 초기화하지 않는다. 플레이어는 언제든지 경쟁전을 시작할 수 있다.

## 5. ELO 시스템

레이스 종료 시 최종 순위와 참가자들의 ELO를 기반으로 조정된다.

- 높은 ELO 상대를 이기면 큰 폭 상승
- 낮은 ELO 상대를 이기면 작은 폭 상승
- 높은 ELO 플레이어가 낮은 ELO 플레이어에게 패배하면 큰 폭 하락
- 비슷한 ELO끼리 경쟁하면 일반적인 변화량 적용

## 6. ELO 계산

순위별 고정 점수를 지급하지 않는다.

| 내 ELO | 상대 평균 | 순위 | 결과 |
|---|---|---|---|
| 1400 | 1500 | 1위 | 큰 폭 상승 |
| 1400 | 1500 | 4위 | 소폭 상승 또는 유지 |
| 1400 | 1500 | 8위 | 큰 폭 하락 |
| 1600 | 1400 | 1위 | 소폭 상승 |
| 1600 | 1400 | 8위 | 큰 폭 하락 |

구체적인 K-factor와 계산식은 프로토타입 이후 데이터를 기반으로 결정한다.

## 7. 티어

| ELO | 티어 |
|---|---|
| 0~999 | Bronze |
| 1000~1199 | Silver |
| 1200~1399 | Gold |
| 1400~1599 | Platinum |
| 1600~1799 | Diamond |
| 1800~1999 | Master |
| 2000+ | Grand Champion |

실제 구간은 테스트 후 조정한다.

## 8. 티어의 역할

티어는 시각적 등급이다. 실제 매칭은 내부 ELO를 우선한다.

- 티어 = 플레이어가 보는 등급
- ELO = 실제 매칭/실력 계산값

## 9. 경쟁 시즌 폐지

8주마다 ELO/랭킹을 초기화하는 구조는 사용하지 않는다. ELO는 지속적으로 유지된다.

## 10. 콘텐츠 시즌

라이브 서비스 콘텐츠는 시즌 단위로 운영한다(Season 1, 2, 3...). 신규 트랙, 부품, 스킨, 코스튬, 이벤트, 시즌 미션, 시즌 패스를 추가하기 위한 개념이다. 콘텐츠 시즌과 경쟁 랭킹은 독립적이다.

## 11. 경쟁 랭킹 유지

콘텐츠 시즌이 바뀌어도 ELO는 유지된다. 시즌마다 Bronze부터 다시 올라갈 필요가 없다.

## 12. 매칭

매칭 기준: ELO, 핑, 대기 시간, 지역.

## 13. 매칭 확장

| 대기 시간 | ELO 범위 |
|---|---|
| 0초 | ±100 |
| 10초 | ±150 |
| 20초 | ±250 |
| 30초 | ±400 |

정확한 값은 서버 데이터로 조정한다. 목표는 실력 차이와 대기시간 사이의 균형.

## 14. 매칭 완료 후 트랙 공개

트랙은 매칭이 완료된 이후 공개한다.

```
MATCH FOUND → PLAYERS READY → TRACK REVEALED
```

## 15. 트랙 공개의 목적

플레이어가 트랙을 미리 알고 차량을 맞춰놓는 것을 방지한다. 매 판 "이번에는 어떤 트랙이 걸렸지?"라는 판단이 발생한다.

## 16. 차량 준비 단계

트랙 공개 후 제한된 준비 시간(예: 30초) 동안 부품 교체, 차량 세팅, 타이어 선택, 스킨 변경, 저장된 프리셋 선택이 가능하다.

## 17. 차량 부품 교체

| 고속 트랙 | 테크니컬 트랙 |
|---|---|
| Low Downforce Wing | High Downforce Wing |
| High Speed Gearbox | Acceleration Gearbox |
| Medium Tire | Soft Tire |

## 18. 차량 스킨 변경

준비 단계에서 스킨 변경 가능. 스킨은 성능에 영향을 주지 않는다. 팀/시즌/개인/이벤트/한정 리버리.

## 19. 준비 시간 제한

카운트다운 종료 시 자동으로 현재 세팅을 확정한다.

## 20. Engineer Recommendation

```
ENGINEER RECOMMENDATION
Recommended: HIGH SPEED SETUP
[APPLY]
```

버튼 하나로 추천 세팅을 적용한다.

## 21. 세팅 프리셋

Balanced / High Speed / High Downforce / Acceleration / Stable. 트랙 전용 세팅이 아니라 기본 플레이 스타일 프리셋 중심.

## 22. 고급 세팅

```
Front Wing       62
Rear Wing        48
Gear Ratio       71
Suspension       55
Brake Balance    57
```

## 23. 차량 부품

엔진 / 프론트 윙 / 리어 윙 / 타이어 / 서스펜션 / 브레이크 / 기어박스 / 에너지 시스템 / 차체

## 24. 차량 스탯

최고속도, 가속, 제동, 코너링, 다운포스, 공기저항, 안정성, 타이어 마모, 브레이크 마모, 엔진 내구도, 에너지 충전, 에너지 출력

## 25. 부품 등급

Common / Rare / Epic / Legendary

## 26. 부품 등급 설계 원칙

높은 등급이 무조건 더 강하지 않다. 등급이 높을수록 튜닝 범위, 특성, 세팅 자유도가 증가한다.

목표: "Legendary를 가지고 있으면 무조건 이긴다"가 아니라 **"Legendary를 어떻게 세팅하느냐가 중요하다."**

## 27. 차량 성능 트레이드오프

- 다운포스 ↑ → 코너링 ↑, 최고속도 ↓
- 기어비 가속형 → 초반 가속 ↑, 최고속도 ↓

모든 트랙에서 하나의 최적 차량이 존재하는 것을 방지한다.

## 28. 타이어

- Soft: 빠르지만 마모가 크다
- Medium: 균형형
- Hard: 느리지만 오래 사용 가능

## 29. 타이어 마모

상태 감소 시 코너링/제동/가속 감소, 미끄러짐 증가.

## 30. 운전 스타일과 마모

- 공격적: 랩타임 감소, 마모 증가, 사고 위험 증가
- 안정적: 랩타임 증가, 마모 감소, 안정성 증가

## 31. 차량 손상

손상 대상: 프론트 윙, 리어 윙, 서스펜션, 브레이크, 타이어, 엔진, 차체

## 32. 충돌 판정

물리 기반. 충돌 속도 + 각도 + 차량 내구도 + 충돌 대상 + 현재 차량 상태를 고려한다.

## 33. 손상 단계

- 경미: 성능 소폭 감소
- 중간: 조향 불안정, 속도 감소, 코너링 감소
- 심각: 성능 크게 감소, 리타이어 가능

## 34. 리타이어

정상 주행 불가 시 DNF. DNF 플레이어는 레이스 종료 / 결과 확인 / 관전이 가능하다.

## 35. Start Protection

레이스 시작 직후 일정 시간 충돌 피해 감소, 차량 간 물리 충돌 완화. 완전 무적은 아니다.

## 36. 역주행 방지

```
역주행 감지 → 경고 → 지속 → 고스트 → 계속 역주행 → 강제 퇴장
```

## 37. 퀄리파잉

기본 방식: 1랩 타임 어택

## 38. 퀄리파잉의 목적

퀄리파잉 결과가 본 레이스의 출발 순서(P1, P2, P3...)를 결정한다.

## 39. 퀄리파잉 충돌

개별 기록 측정 방식. 플레이어끼리 직접 충돌하지 않는다. 서버가 기록을 비교한다.

## 40. 퀄리파잉 UI

```
QUALIFYING
P1  PlayerA      1:28.421
P2  YOU          1:28.592
P3  PlayerC      1:28.731
```

표시: 현재 순위, 섹터 기록, 베스트랩, 폴 포지션 예상

## 41. 그랑프리

```
QUALIFYING → GRID → COUNTDOWN → RACE → FINAL LAP → FINISH
```

## 42. 그랑프리 핵심 시스템

주행, 추월, 슬립스트림, 에너지, 타이어, 피트, 차량 손상

## 43. 레이스 길이

목표: 5~15분

## 44. 피트스톱

타이어 교체, 차량 수리

## 45. 피트 시간

목표: 약 2.5~5초. 완전 랜덤이 아니라 기본 작업 시간 + 피트 크루 능력 + 작업 효율 기반.

## 46. 피트 전략

- 1 Stop: Soft → Medium
- 2 Stop: Soft → Soft → Soft

트랙과 플레이 스타일에 따라 달라진다.

## 47. 에너지

주행 중 충전. 사용 시 가속 증가, 최고속도 증가, 추월 능력 증가.

## 48. 에너지 전략

에너지 저장 후 마지막 랩 사용, 또는 매 랩 직선에서 사용 등 플레이어 전략에 따라 다르게 사용.

## 49. 슬립스트림

앞 차량 뒤에서 주행 시 공기저항 감소 → 직선 속도 증가, 추월 기회 증가. 추월을 가능하게 하는 핵심 시스템.

## 50. 추월

최고속도, 가속, 코너 탈출, 에너지, 슬립스트림, 주행 라인, 차량 세팅이 영향을 준다.

## 51. DRS 계열 시스템

핵심 시스템으로 확정하지 않는다. 슬립스트림만으로 충분한지 먼저 테스트한다.

## 52. 에너지 존

후순위 기능. 프로토타입에서 전략적 가치, 복잡도, 밸런스를 검증 후 결정.

## 53. 트랙

실제 유명 서킷에서 영감을 받은 독창적인 트랙을 제작한다. 실제 트랙을 그대로 복제하지 않는다.

## 54. 트랙 유형

고속 / 시가지 / 테크니컬 / 고저차 / 복합 코너

## 55. 트랙 랜덤

매칭 완료 후 트랙을 랜덤 선정. 연속 등장 방지 로테이션 시스템 사용.

## 56. 트랙별 차량 세팅

```
TRACK → ANALYZE → SETUP
```

플레이어는 즉각적인 판단을 내려야 한다.

## 57. 조작

가속, 브레이크, 조향, 에너지, 피트, 카메라

## 58. 주행 보조

조향 보조, 브레이크 보조, 레이싱 라인, 트랙 가이드. 숙련 플레이어는 끌 수 있다.

## 59. 차량 물리

속도, 마찰, 다운포스, 공기저항, 타이어 상태, 차량 무게, 노면, 조향, 충돌

## 60. 레이싱 라인

올바른 라인은 코너 탈출 속도 증가, 랩타임 감소, 타이어 부담 감소 효과를 가진다.

## 61. 레이스 HUD

```
LAP 4 / 8
P1 PlayerA
P2 YOU        +0.421
P3 PlayerC    +1.182
```

표시: 랩, 순위, 앞뒤 차량과의 거리, 타이어, 손상, 에너지, 피트 상태

## 62. 미니맵

플레이어, 경쟁자, 피트, 결승선, 트랙 진행도

## 63. 결과 화면

```
RACE RESULT
P1 PlayerA
P2 YOU
P3 PlayerC
```

추가: 베스트랩, 총 레이스 시간, 피트 시간, 사고, 타이어, ELO 변화

## 64. ELO 결과 화면

```
RATING RESULT
ELO 1428 → 1451  (+23)
```

변화 이유를 표시할 수 있다.

## 65. ELO 보호/악용 방지

신규 계정 배치 경기, 비정상적 반복 탈주 탐지, 고의적 ELO 하락 방지, 파티를 이용한 랭킹 조작 방지, 비정상 레이스 기록 탐지

## 66. 탈주

ELO 손실, 탈주 카운트, 반복 시 매칭 제한. 네트워크 오류와 고의 탈주를 구분하도록 설계한다.

## 67. 친구 시스템

친구 추가, 온라인 상태, 프로필, 일반전 초대. 경쟁전 파티는 랭킹 악용 여부를 고려해 후속 설계.

## 68. 일반전

ELO 변화 없음, 자유로운 차량 테스트, 친구와 플레이, 세팅 테스트

## 69. Garage

차량 확인, 부품 교체, 튜닝, 세팅 저장, 스킨, 성능 분석

## 70. 차량 성능 분석

```
TOP SPEED       348 km/h
ACCELERATION    82
BRAKING         91
HANDLING        82
DOWNFORCE       74
TYRE WEAR       MEDIUM
```

## 71. 엔지니어

차량 세팅을 분석하고 추천한다.

> "이 트랙은 긴 직선이 많습니다. 다운포스를 낮추는 것을 추천합니다."
> "현재 Soft 타이어의 예상 마모가 높습니다. Medium을 고려하십시오."

## 72. 패배 분석

```
WHY DID YOU LOSE?
Top Speed        -0.7s
Cornering        +0.3s
Pit Time         +1.8s
Tyre Degradation +1.1s
Driving          +0.9s
```

플레이어가 다음 레이스에서 개선할 수 있도록 한다.

## 73. 가상 팀

실제 F1 팀을 사용하지 않는다. 예: Apex Racing, Nova Motorsport, Orion GP, Titan Racing, Velocity Works

## 74. 팀의 역할

초기에는 브랜드, 리버리, 세계관, 수집 콘텐츠 중심. 팀 단위 경쟁은 후속 시스템.

## 75. 리버리

기본 / 팀 / 시즌 / 이벤트 / 한정 / 챔피언

## 76. 드라이버

캐릭터는 핵심 경쟁 시스템이 아니다. 커스터마이징: 헬멧, 레이싱 슈트, 장갑, 신발, 프로필 포즈

## 77. 상점

CAR / PARTS / LIVERY / HELMET / SUIT / PIT CREW / EFFECT / SPECIAL

## 78. 스킨/외형의 성능 분리

스킨과 코스튬은 성능에 영향을 주지 않는다. 모든 경쟁 성능은 게임플레이로 획득 가능해야 한다.

## 79. 가챠

도입 시 경쟁 성능이 아닌 외형 중심(리버리, 헬멧, 슈트, 이펙트, 프로필 아이템).

## 80. 과금 원칙

**돈을 많이 쓴 플레이어가 ELO를 쉽게 올릴 수 있는 구조를 만들지 않는다.**

## 81. 부품 획득

일반전, 경쟁전, 미션, 이벤트, 제작, 보상

## 82. 콘텐츠 시즌

경쟁 ELO는 유지하되 콘텐츠는 시즌 단위로 추가한다.

## 83. 시즌 패스

후속 시스템. 무료(기본 외형, 재화, 아이템) / 프리미엄(한정 리버리, 코스튬, 이펙트, 장식). 경쟁 성능을 직접 구매하는 구조는 지양한다.

## 84. 시즌 미션

10회 완주, 5회 포디움, 3회 폴 포지션, 특정 트랙 5회 완주, 피트 10회 등

## 85. 프로필

닉네임, ELO, 티어, 최고 ELO, 우승 횟수, 포디움, 폴 포지션, 베스트랩, DNF, 총 레이스

## 86. 리플레이

재생, 일시정지, 배속, 카메라 변경, 플레이어 선택

## 87. 관전

DNF 또는 레이스 종료 후 다른 플레이어 관전 가능

## 88. 날씨

후속 기능: 맑음, 흐림, 비, 젖은 노면. 도입 시 타이어, 제동, 마찰, 시야가 변경된다.

## 89. 서버 권위

경쟁전에서 서버가 위치, 속도, 충돌, 랩, 순위, 완주, ELO를 판정한다.

## 90. 네트워크 보정

핑 차이로 인한 억울한 충돌을 최소화한다. 위치 보간, 예측, 서버 검증, 충돌 보정.

## 91. 퀄리파잉 네트워크 최적화

```
Player → 1 Lap → Time → Server → Ranking
```

## 92. Anti-Cheat

서버에서 최고속도, 위치, 랩타임, 이동 거리, 충돌, 결과를 검증한다.

## 93. UI 구조

RACE / GARAGE / SHOP / RANKING / PROFILE / SETTINGS

## 94. 홈 화면

프로 레이싱 팀의 차고를 모티브로 한다. 중앙에 플레이어 차량, 주변에 피트 크루, 모니터, 정비 장비, 시즌/이벤트 정보.

## 95. 튜토리얼

```
기본 조작 → 차량 → 자동 세팅 → 퀄리파잉 → 그랑프리 → 타이어 → 피트 → 에너지 → 고급 세팅
```

처음부터 모든 시스템을 설명하지 않는다.

## 98. 클럽/크루

## 103. 설계 원칙

1. **운전이 가장 중요하다** — 세팅이 아무리 좋아도 운전을 못하면 이길 수 없어야 한다.
2. **차량 세팅은 차이를 만든다** — 하지만 세팅만으로 승패가 결정되어서는 안 된다.
3. **트랙은 매칭 이후 공개한다** — 매 판 즉석 판단을 만든다.
4. **ELO는 지속된다** — 강제 시즌 리셋을 하지 않는다.
5. **콘텐츠 시즌과 경쟁 랭킹을 분리한다**
6. **RNG는 통제한다** — 피트/충돌 등 중요한 결과가 단순 운으로 결정되지 않게 한다.
7. **Pay-to-Win을 방지한다** — 실력과 전략이 핵심이 되어야 한다.

## 105. 최종 제품 정의

이 게임의 경쟁 구조는 시즌을 끝내기 위해 달리는 구조가 아니다. 플레이어는 언제든지 경쟁전에 들어가고, 매칭 → 트랙 공개 → 차량 준비 → 퀄리파잉 → 그랑프리를 하나의 완결된 경쟁 경험으로 즐긴다.

장기적인 목표는 시즌 포인트가 아니라 **"내 ELO를 어디까지 올릴 수 있는가?"** 가 된다.

콘텐츠 시즌은 경쟁 랭킹을 초기화하기 위한 장치가 아니라 새로운 트랙, 부품, 스킨, 이벤트를 공급하는 라이브 콘텐츠 구조로만 사용한다.

## 106. 게임의 최종 핵심 문장

> **"매칭이 잡히기 전에는 아무도 이번 레이스를 완벽하게 준비할 수 없다."**

트랙이 공개되는 순간 플레이어는 판단해야 한다. 어떤 부품을 장착할 것인가? 어떤 타이어를 사용할 것인가? 다운포스를 얼마나 줄 것인가? 예선에서 얼마나 공격적으로 달릴 것인가?

결국 승패를 결정하는 것은 **차량 설계 + 순간적인 세팅 판단 + 전략 + 운전 실력**이다.
